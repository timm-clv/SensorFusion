## 📁 Project Architecture

* **`CAD Model/`**: 3D CAD models of the embedded platform’s structure.
* **`sensor_platform_ws/`**: Main workspace (ROS2) containing packages and source code.
* **`calibration/`**: Configuration files and sensor calibration parameters.
* **`analysis/`**: Rosbags and scripts related to result analysis.
* **`datasheet/`**: Detailed technical data sheets for the components and sensors used.
* **`report/`**: Reports, specifications, and project information.
* **`image-video/`**: Video and image resources used for illustration.
* **`tf_tree.pdf`**: Diagram of the system’s transformation tree (TF Tree).
* **`.gitignore`**: Configuration of exclusion rules for Git.

For more information on the project’s implementation, see the report [here](report/Visual Inertial Data Collection Platform and Sensor Fusion Benchmarking.pdf) .
